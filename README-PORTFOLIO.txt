# Iyaaz Muhammad Shabaz — Portfolio

This is a flat GitHub Pages website. Keep every file in the repository root.

## Files
- HTML pages: `index.html`, `about.html`, `projects.html`, `certifications.html`, `research.html`, `contact.html`
- Stylesheet: `style.css`
- JavaScript: `data.js`, `main.js`
- Resume: `resume.pdf`
- Certificate images: `cert-html.jpg`, `cert-css.jpg`, `cert-codenexus.jpg`, `cert-chakravyuha.jpg`

Do not move these files into folders unless you also update the paths in the HTML and `data.js`.

For GitHub Pages, choose Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
