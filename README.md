# Iyaaz Muhammad Shabaz — Portfolio

A static six-page portfolio built with HTML, CSS, jQuery and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. The site uses jQuery 3.7.1 and Google Fonts from CDNs, so an internet connection is needed for those external assets.

## Content
Edit `js/data.js` to update the biography, projects, research, certificates, skills, education and achievements.

## Personal assets
- `assets/resume.pdf` is included.
- Add a square profile image as `assets/photo.jpg`.
- Add certificate scans/images under `assets/certs/` and set the matching `image` path in `js/data.js`.
- Add project screenshots under `assets/projects/` if desired.

## Contact form
The form validates input and opens the visitor's default email application with a prefilled message. For direct website-to-email delivery, configure a Formspree endpoint in `SITE.contactFormEndpoint` in `js/data.js`.

## Deploy
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
